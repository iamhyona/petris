# PETRIS

게임보이 느낌의 웹 블록 퍼즐 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

## 조작

휴대폰 (화면 어디서나)
- 좌우로 밀기: 이동
- 위로 쓸어올리기 또는 탭: 회전
- 아래로 천천히 밀기: 천천히 내리기
- 아래로 빠르게 튕기기: 빨리 내리기
- 왼쪽 정보 칸 탭: 잠시 멈춤 (멈춤 화면에서 음악 켜기/끄기)

PC (키보드)
- ← → 이동, ↑ 회전, ↓ 천천히 내리기, Space 빨리 내리기
- Enter / P 시작·멈춤, M 음악

## 대결

- 온라인 대결: 시작 화면 VS 대결 → 방 만들기 / 4자리 코드로 참가
- PC 2인용: 시작 화면 2P (PC) 또는 주소 끝에 `?local` — P1은 WASD+Space, P2는 방향키+Enter

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages로 배포하면 누구나 주소로 접속해 플레이할 수 있습니다.
